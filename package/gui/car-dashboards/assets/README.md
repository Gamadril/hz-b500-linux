# HMI artwork

Artwork added for this port. None of it is covered by the imported dashboards'
MIT notice, and no separate redistribution licence was supplied.

| Files | Source | Use |
| --- | --- | --- |
| `pdc-car.png` | `canbus_mod/assets/full_body.png` from [hz-b500-mods](https://github.com/Gamadril/hz-b500-mods) | Parking-sensor view |
| `vehicle/*.png` | BMW E90 dashboard reference project (`assets/`) | Body, door, light and indicator layers on Home |
| `dashboard-fuel.svg` | Open Icons gas pump, border removed | Dashboard fuel dial |
| `launcher/*.png` | Round icon set, scaled to 96×96 | Home launcher tiles |

The build converts the PNGs into compact `*.hzp` images in the build output;
the sources stay unchanged.
